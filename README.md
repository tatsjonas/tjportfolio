# Cybex Media Website

Original responsive one-page website created for Cybex Media, inspired by the editorial/cinematic structure of the supplied Tilia reference without copying the theme code.

## Files
- `index.html` — site structure and content
- `styles.css` — full responsive design system and animations
- `script.js` — menu, scroll reveal, showreel modal, testimonial slider, sticky header and cursor effects

## How to preview
Open `index.html` in a modern browser. An internet connection is required for the current Google Fonts and demo imagery.

For best local preview, run a tiny local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Before launch
1. Replace all demo Unsplash images with your own Cybex Media project stills.
2. Replace the showreel placeholder in `index.html` with your YouTube/Vimeo/self-hosted video embed.
3. Confirm the company email, phone, social links and physical address.
4. Add real client testimonials and portfolio project links.
5. Connect the final domain and hosting.
